Base de Datos II

Diagrama funcional en MongoDB

El sistema trabaja con una base de datos NoSQL en MongoDB. La colección principal de catálogo es productos, poblada con 1000 documentos de la temática NextLevel Store. También se cargan las colecciones categorias, usuarios y pedidos.

En MongoDB no hablamos de filas tradicionales, sino de documentos dentro de colecciones. Por eso, para la sustentación se presenta como una colección productos con 1000 registros/documentos.

Colecciones principales

ColecciónFunción dentro del sistema
usuariosRegistra clientes, administradores, roles, bloqueo y métodos de pago simulados.
categoriasClasifica el catálogo en Gamer, Anime, Superhéroes, Coleccionables y Ropa.
productosAlmacena los 1000 documentos del catálogo con precio, stock, imagen y estado activo.
pedidosGuarda las compras realizadas, sus productos, total, estado de pago y seguimiento.

Métodos MongoDB aplicados

  • findAll(): listar productos, pedidos y categorías.
  • findById(): consultar productos para detalle, edición y compra.
  • save(): crear o actualizar usuarios, productos y pedidos.
  • deleteById(): eliminar productos desde administración.
  • existsByCorreoIgnoreCase(): validar si un correo ya existe antes de registrar.
